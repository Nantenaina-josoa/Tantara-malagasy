# Tantara Malagasy — version hors connexion

Ouvrir `index.html` après avoir extrait entièrement l’archive ZIP. Toutes les pages, les images, le CSS, le JavaScript et Bootstrap sont locaux. Les icônes sont des SVG locaux dessinés pour remplacer les dépendances Boxicons sans connexion. Les polices utilisent celles du système (Arial/Helvetica).

Les favoris, les langues et le thème sont enregistrés dans localStorage (leur persistance peut varier selon le navigateur pour les pages ouvertes en file://). Le formulaire de contact utilise l’application mail de l’appareil et nécessite un service de messagerie pour envoyer effectivement un message.

Aucune ressource CDN n’est requise.
